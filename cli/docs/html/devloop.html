Petri CLI Devloop

Repeatable checks for agents, worktrees, and local development.

One Command

scripts/devloop.sh

The script runs the same core checks expected in CI:

cargo fmt -- --check
CARGO_BUILD_JOBS=1 cargo check --locked --bin petri -j1
CARGO_BUILD_JOBS=1 cargo test --locked -j1 -- --test-threads=1

Windows Command Shim

node scripts/check-petri-launcher.mjs

This validates the installation/update-only Petri launcher used before a native Rust binary is available. Bare Petri should show the CLI front door without backend noise; market commands require the Rust binary, and the launcher never answers a market command itself.

Red Green Refactor

For parser, endpoint, math, chart, or signing changes, add the failing test first when the behavior can be isolated. Keep TUI layout changes small enough that a PTY smoke test can still catch obvious regressions.

Native Windows TUI Acceptance

tools/petri-conpty-harness/run.ps1

The standalone, development-only ConPTY harness runs the release binary with isolated loopback data, provider access off, no wallet, current-screen VT parsing, native keyboard/mouse/resize input, hard deadlines, and a watchdog worker per scenario. It is not linked into or shipped with Petri. Read the harness isolation contract before extending it.

Unix PTY Smoke

script -q /tmp/petri-smoke.log petri

Exit with q, then inspect the log. Either PTY check supplements, rather than replaces, browser-parity, backend, wallet, and on-chain checks.

CI Shape

The workflow template at docs/ci/petri-cli-ci.yml checks out only this repository. scripts/devloop.sh runs the research and MCP bridge checks, the locked format, check, test and clippy gates, then the research binary smoke and the MCP server check. After those pass, the active workflow runs the launcher, native packaging, bundled-guide and dependency-license checks. The signed release is the monorepo's .github/workflows/cli-release.yml, run by hand on a vX.Y.Z tag: it builds the production binaries (Linux, signed and notarized macOS, Authenticode-signed Windows), checks they default to production without the dev faucet, and opens a draft release.

Subagent Handoff
